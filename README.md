# Student Registration System 🎓

A CLI-based Student Registration System built in Python using
Object-Oriented Programming and JSON file storage.

---

## 👨‍💻 Author
**Mukesh K**
B.Tech Information Technology | VSB College of Engineering Technical Campus

---

## 🚀 Features
- Add new students (with duplicate ID check)
- View all students
- Search student by ID
- Update student details (with duplicate ID check on new ID)
- Delete student records
- Persistent storage using JSON file
- Input validation using exception handling

---

## 🛠️ Tech Stack
- Python 3
- JSON (Data Storage)
- Object-Oriented Programming

---

## ⚙️ How to Run

```bash
# Clone the repository
git clone https://github.com/yourusername/student-registration-system.git

# Navigate to project folder
cd student-registration-system

# Run the program
python3 student_app.py
```
